# 吉他指法查询器

在线使用：https://eason-xi.github.io/guitar-fingering/

单文件 HTML 的吉他和弦 / 音阶指法查询工具。双击 `index.html` 即可在浏览器里使用，无需构建、无需安装。

## 功能

- 12 个根音 × 19 种和弦类型，每种最多给出 6 个常用按法
- 和弦图带手指编号与横按标注，根音用黄铜色标出
- 逐弦详解：弦 / 品 / 指 / 音名 / 级数；支持扫弦、分解试听
- 15 品全指板音位图，可在「音名」与「级数」之间切换
- 8 种音阶（大调、自然小调、大五声、小五声、布鲁斯、多利亚、混合利底亚、和声小调）
- 大调 / 小调附顺阶和弦，可一键跳到和弦视图
- 5 种调弦（标准、Drop D、降半音、Open G、DADGAD）
- 0–7 品变调夹（按实际音高推算，夹位以下品位灰显）、左手持琴、♯/♭ 记谱切换
- 指板可一键切换横排 / 竖排，竖排在手机上无需横向滑动
- 「自由指板」可点击任意弦位发声并打标记，标记音可整体试听
- Web Audio 发声：扫弦、分解、音阶上行 / 下行、单击音位

## 说明

指法由前端算法实时推算（穷举 + 打分筛选），并非硬编码的和弦表，个别指型可能与市面教材不同，以实际手感为准。

## 使用

用浏览器打开 `index.html`，或部署到任意静态托管；放到 GitHub Pages 根目录即可直接访问。
